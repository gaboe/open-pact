# Control contracts by platform

The table defines the intended result for each registered value. `unknown` means the available evidence cannot establish a result. `n/a` is an explicit provider scope decision. Numeric values are integers. `null` is JSON null, not a string.

The primary OS sources are linked in each row. They describe the intended behavior, including known differences from this client revision. They do not change the signed value domains. DS3 managed repository values are outside this table.

`screen_lock` measures total inactivity before a password-protected lock. The boundaries are 300 and 900 seconds. Patch and signature ages use completed elapsed days from 0 through 3650. Other numeric values range from 0 through 2147483647. Future timestamps give `unknown`.

Disk scope is the startup data volume on macOS and Windows. Linux scope is mounted writable persistent local block storage and swap. Boot-only partitions, removable media, and RAM storage are excluded.

The portable [contract runner](../crates/open-pact-client/src/checks/contracts.rs) reads one [JSON case file per value](../crates/open-pact-client/tests/contracts). It calls the existing parsers and the package-host seam. Registry constants run through their registered function. `known_diff` records a contract difference and skips that case. Test output lists each skip. Pending Linux preboot and macOS browser cases follow the branches named in the task brief.
